# Фаза 4.3: TF-IDF по леммам vs BERTA-эмбеддинги (issue #70)

Честное сравнение двух конвейеров кластеризации фраз на одном наборе:
одинаковый k-means, разные представления. Скрипт — `scripts/issue13_tfidf_vs_berta.py`
(по образцу `scripts/experiment_vector_d.py`), результат — JSON в stdout.

## Набор фраз

50 фраз, 5 ожидаемых тем по 10 фраз: три seed-фразы фикстур Фазы 1
(«новогодние подарки», «купить телефон», «курсы английского») + словарь
похожих и разных фраз («мебель», «доставка еды»). Ожидаемая разметка —
ground truth для ARI-vs-expected; сами конвейеры меток не видят
(k-means, без supervised-сигнала).

## Метрики

- **силуэт** (silhouette_score) на представлении с итоговыми метками;
- **ARI между seed'ами** k-means (0, 1, 2, 42) — стабильность к инициализации:
  среднее и минимум по всем парам;
- **ARI vs expected** — согласованность итогового разбиения с ground truth;
- **интерпретируемость** — топ-леммы кластера (только TF-IDF: у BERTA
  представление не в пространстве лемм) и топ-фразы кластера по близости
  к центроиду (оба конвейера).

## Результат фикстурного прогона

Прогон от 2026-09-09, macOS, `uv sync --extra dev --extra nlp`,
BERTA `sergeyzh/BERTA` (task `clustering`, лемматизированные фразы),
sklearn 1.7.2. (huggingface.co с машины автора недоступен — модель скачана
через зеркало `HF_ENDPOINT=https://hf-mirror.com`, на прогоны не влияет.)

| Конвейер | Силуэт | ARI vs expected | ARI seed-стабильность (mean/min) | Разбиение |
|---|---|---|---|---|
| TF-IDF по леммам | 0.281 | 0.470 | 0.507 / 0.434 | смартфоны + мебель слились в кластер из 20 фраз; «подготовка к ielts» уехала в смешанный кластер; «новогодние подарки» распались на 2 кластера (5+8) |
| BERTA + k-means | 0.327 | 0.948 | 0.974 / 0.948 | почти идеальное: 11/9/10/10/10, одна фраза мигрировала между темами (ARI 0.948 ≈ одна перестановка пары) |

Интерпретируемость (топ-фразы кластеров, BERTA): каждый кластер —
чистая тема («купить диван…» — мебель; «курсы английского…» — обучение;
«купить смартфон…» — техника; «доставка еды…» — еда; «подарки на новый
год…» — праздники). Топ-леммы TF-IDF подтверждают картину его слабости:
в кластерах мешаются «купить/диван/телефон/смартфон», «для», «на» —
общие леммы связывают несравнимые темы.

Силуэт сравнивать между строками осторожно: он считается в разных
пространствах (разреженный TF-IDF против плотного 768-мерного BERTA) и
чувствителен к размерности. ARI — основная метрика: она безразмерна к
представлению и сравнивает разбиения напрямую.

## Вывод

**Положительный результат для трансформера.** На наборе из 50 фраз
5 тем BERTA + k-means решает задачу кластеризации фраз заметно лучше
TF-IDF: ARI против ожидаемых тем 0.948 vs 0.470, стабильность к
инициализации 0.97 vs 0.51. TF-IDF по леммам систематически связывает
темы общими словами («купить», «на», «для») — лексическое пересечение
в коротких запросах Рунета слишком велико для мешка лемм.

Что это значит для витрины:

- **~2 ГБ зависимостей оправданы** для шага кластеризации фраз, НО они
  остаются в extra `nlp` (базовая установка и CI их не тянут) — гейт
  `scripts/check_no_llm.py` не затронут, sentence-transformers/torch в
  основные зависимости не переезжают.
- TF-IDF-конвейер сохраняется как лёгкий fallback (без extra `nlp`)
  и как baseline для будущих сравнений: он детерминирован, быстр и
  не требует модели, но его разбиение на коротких русских запросах
  некачественно (ARI 0.47).
- Ограничение эксперимента: 50 фраз, 5 тем, один прогон. Убедительная
  победа BERTA (разрыв ARI 0.48) не зависит от этих оговорок, но
  количественные числа не переносимы на произвольный корпус.
