# Карточка датасета

Срез данных, на котором считаются все метрики проекта (MVP #23, склейка окон
#6, сезонная структура #32 и далее). Формат сырых файлов и происхождение
замера описаны в [`DATA.md`](DATA.md); этот документ — краткая карточка
именно среза: что в данных, сколько и с какими особенностями.

Все факты ниже перепроверены прогоном
[`src/wordstat_trends/loader.py`](../src/wordstat_trends/loader.py)
(`load_run`) по фикстурам `tests/fixtures/dynamics_*.csv` — дословным
выгрузкам Вордстата из замера #2 (2026-08-21, `--keep-raw`).

## Срез

| Параметр | Значение |
|---|---|
| Фразы | 3: «купить телефон» (высокочастотная), «курсы английского языка» (среднечастотная), «новогодние подарки» (сезонная) |
| Регион | Россия (один для всех фраз) |
| Устройства | все устройства |
| Окно | 24 месяца: 08.2024–07.2026 (август 2024 — июль 2026, дефолтный диапазон интерфейса на дату замера) |
| Гранулярность | месяц (`period` = `YYYY-MM`) |
| Точек на фразу | ровно 24, пропусков нет |
| Представление | `dynamics` (другие представления сборщика в срез не входят) |

## Что отдаёт загрузчик

`load_run()` на каждой фикстуре даёт DataFrame из 24 строк, отсортированных
по периоду, с колонками:

- `period` — `YYYY-MM`, месячная метка (в сыром CSV — русский текст,
  «август 2024», разбирается `parse_period`);
- `queries` — `int64`, «Число запросов» (тысячи через ASCII-пробел в сыром
  виде: `997 977`);
- `share_pct` — `float`, «Доля от всех запросов, %» (десятичная запятая в
  сыром виде: `0,0115` = 0.0115%).

Метаданные прогона (`phrase`, `region`, `created_at`, `dtypes`) лежат в
`df.attrs` из `manifest.json`.

## Известные особенности формата

- **UTF-8 с BOM** (`EF BB BF`) — читается как `utf-8-sig`.
- **CR-only переводы строк** (`\r`, без `\n`) — наивные ридеры видят «файл в
  одну строку»; загрузчик читает через `splitlines()`/`csv` (см. `DATA.md`).
- **Разделитель полей `;`, десятичная запятая**, тысячи через ASCII-пробел.
- **Четвёртая колонка** (длинный заголовок графика) пустая во всех строках —
  loader её отбрасывает.
- **`top_popular` и `top_related` пусты** во всех трёх прогонах замера #2
  (0 строк данных, баг сборщика — см. `DATA.md`): загрузчик принимает только
  `dynamics` и поднимает `EmptyDatasetError` на пустой датасет, а не молчит.

## Ограничения среза

- 24 точки = ровно два сезонных цикла — минимум для `sp=12`; для устойчивой
  сезонной декомпозиции рабочие прогоны используют окно 60 месяцев (5 лет),
  см. [`DATA.md`](DATA.md#выбранный-период-сбора-пять-лет-помесячно-issue-5).
- Аналитические выводы EDA-ноутбука (issue #62) будут добавлены отдельной
  правкой после его мержа; карточка описывает только верифицируемые
  программой факты среза.
