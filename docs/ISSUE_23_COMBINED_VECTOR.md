# Issue #23: объединённый вектор (sp=7 + sp=12) как представление спроса

Третья итерация MVP [issue #23](https://github.com/axisrow/wordstat-trends/issues/23),
поверх смёрженного фундамента:

- [`docs/EXPERIMENT_VECTOR_D.md`](EXPERIMENT_VECTOR_D.md) — итерация 1
  (sp=12, месячные фикстуры: рефит физически неисполним на 24 точках,
  сезонный вектор существует только при `information_criterion="aic"`) и
  итерация 2 (sp=7, дневные фикстуры: форма профиля устойчива,
  corr ≥ 0.994, но параметризация mul/add плывёт между рефитами; у
  high_freq недельной компоненты нет вовсе);
- [`docs/ISSUE_32_SEASONAL_STRUCTURE.md`](ISSUE_32_SEASONAL_STRUCTURE.md) —
  `has_seasonal` есть исход решающего правила «loglik против штрафа
  критерия», а не измеренное свойство ряда;
- [`docs/ISSUE_34_WINDOW_THRESHOLD.md`](ISSUE_34_WINDOW_THRESHOLD.md) —
  пороги окна для детекции sp=7.

Скрипт: [`scripts/issue23_combined_vector.py`](../scripts/issue23_combined_vector.py).
Запуск: `PYTHONPATH=. python -m scripts.issue23_combined_vector`
(таблицы — stdout, полный JSON — `/tmp/issue23_combined_vector_results.json`).

**Дата прогона:** 2026-09-08. Данные — те же фикстуры: дневные
(56-дневное train-окно 23.06–17.08.2026, `[8]*7` подтверждено загрузчиком)
и месячные (24 точки, 2024-08 — 2026-07). Новых выгрузок нет, существующие
эксперименты не дублируются — используются их зафиксированные выводы.

## Вопрос этой итерации

Не «устойчивы ли коэффициенты» — ответ по частям уже известен (см. выше),
а вопрос из формулировки issue: **работает ли объединение двух блоков как
ПРЕДСТАВЛЕНИЕ спроса** — меняет ли объединённый вектор отношения близости
между фразами по сравнению с одинарными sp, и сохраняется ли это отношение
при рефитах. Гипотеза #23: вектор фиксированной длины — представление
спроса, дальнейшая работа (кластеризация, поиск ниш) идёт над векторами.

## Дизайн (зафиксирован до прогона)

1. **Блоки на фразу** (обе конвенции — из раздела 1 соответствующих
   итераций EXPERIMENT_VECTOR_D):
   - sp=7: дневной train-окон 56 дней, `AutoETS(sp=7, aic)`;
   - sp=12: месячный ряд 24 точки, `AutoETS(sp=12, aic)` — единственный
     критерий, при котором месячный сезонный блок существует (итерация 1:
     при aicc оба бэкенда отвергают сезонность на всех трёх фикстурах).
2. **Объединение**: конкатенация блоков, каждый приведён к z-оценке
   (среднее 0, std 1). Обоснование — установленное в EXPERIMENT_VECTOR_D
   свойство: корреляция Пирсона scale/shift-инвариантна и потому остаётся
   валидной через смену параметризации mul/add, тогда как MAE и абсолютные
   сдвиги — нет (итерация 2, «курсы английского»). Z-скоринг делает блоки
   безразмерными. **Веса блоков не выравниваются намеренно**: корреляция
   конкатенации учитывает, что годовой блок несёт 12 координат против 7 у
   недельного; блочные корреляции репортятся отдельно, так что эффект
   длины блока виден явно.
3. **Блок с `has_seasonal=False`** — нулевой вектор по построению;
   сходство с его участием — NaN (не 0), репортится как `null`.
4. **Структура представления**: три попарные корреляции между тремя фразами
   в трёх представлениях {sp7, sp12, combined} + ближайший сосед каждой
   фразы + упорядочение пар по убыванию близости («отпечаток» структуры).
5. **Устойчивость структуры**: рефит только дневного блока (−7 и −14 дней,
   сетка итерации 2). Месячный блок фиксирован — его рефит неисполним на
   24 точках (итерация 1), поэтому проверена только sp=7-часть
   представления; это репортится явно, не выдаётся за устойчивость
   combined-вектора в целом.

Пункт 3 issue #23 (осмысленность кластеров «глазами») и пункт 4
(сравнение с эмбеддингами) на трёх фразах статистически неисполнимы и
НЕ выполняются — как в итерациях 1–2.

## Что измерено

### 1. Блоки на полном train-окне

| Фраза | sp=7 (56д) | sp=12 (24м) |
|---|---|---|
| новогодние подарки | mul/add/mul, сезонный | mul/add/mul, сезонный |
| купить телефон | add/None/**None** — блока нет | mul/None/mul, сезонный |
| курсы английского | mul/add/mul/damped, сезонный | mul/None/mul, сезонный |

Соответствует зафиксированному: high_freq не имеет недельного блока
(итерация 2, #32 — «граничный случай» по амплитуде), но имеет месячный
(итерация 1, при aic). Диагностика месячного блока (циклы 1↔2 одного
фита): corr 0.998 / 1.000 / 1.000 — с той же оговоркой итерации 1, что
это не внешняя устойчивость.

### 2. Структура представления: одинарные sp против объединённого

Попарные корреляции (полное окно):

| Пара | sp7 | sp12 | combined |
|---|---:|---:|---:|
| подарки ↔ телефон | null (блока нет) | 0.372 | 0.296 |
| подарки ↔ курсы | **0.989** | **0.024** | 0.380 |
| телефон ↔ курсы | null (блока нет) | 0.354 | 0.281 |

Ближайший сосед «новогодних подарков»:

| Представление | Сосед | sim |
|---|---|---:|
| sp7 | курсы английского | 0.989 |
| sp12 | **купить телефон** | 0.372 |
| combined | курсы английского | 0.380 |

Три факта:

- **Блоки несут разную дискриминацию, и она комплементарна.** Недельный
  профиль объединяет «подарки» и «курсы» почти в одну точку (0.989 —
  одинаковая форма будни/провал-в-субботу, итерация 2); годовой профиль
  эти же фразы разводит почти до ортогональности (0.024 — декабрьский
  пик против сентябрьского). Одинарный sp=7 к тому же оставляет две пары
  неопределёнными (нет блока у high_freq) — представление из 7 чисел
  физически не может сравнить треть фраз.
- **Combined — единственное из трёх представлений, в котором определены
  все три пары и ни одна пара не слита.** Максимальная близость в нём
  0.380 против 0.989 у sp7: добавление годового блока разводит фразы,
  которые недельный профиль склеивал.
- **Выбор представления меняет топологию ниш.** Ближайший сосед самой
  сезонной фразы — «курсы английского» по sp7, но «купить телефон» по
  sp12; combined возвращает соседство к «курсам». Ни одно из трёх
  представлений не «правильно» само по себе — вопрос, какая близость
  содержательна для витрины, на трёх фразах не решается (пункт 4 issue).

### 3. Устойчивость структуры при рефитах дневного блока

Отпечаток (упорядочение пар) и ближайшие соседи — на обоих рефитах
(−7 и −14 дней) сохранены во **всех трёх** представлениях. Числа combined
почти не двигаются: подарки↔курсы 0.380 → 0.380 (−7д) / 0.376 (−14д),
подарки↔телефон 0.296 (не меняется — пара определяется месячным блоком),
телефон↔курсы 0.281. Согласуется с итерацией 2 (форма профиля устойчива,
corr ≥ 0.994): **отношения близости между фразами устойчивее самих
коэффициентов** — параметризация блоков при этом плывёт (у «подарков»
sp7 mul→add на −14д, у «курсов» mul/damped→add/damped), но z-скоринг +
корреляция, как и рассчитывалось, сравнение через смену параметризации
переживают.

`representation_stability_combined`: fingerprint и соседи стабильны на
обоих рефитах — **с явной оговоркой**: проверена только sp=7-часть;
устойчивость combined-вектора в целом этим прогоном НЕ подтверждается.

## Вывод

**Представление механически работает; содержательная осмысленность — не
проверена, и на имеющихся данных не проверяема.**

1. Объединённый вектор фиксирует обе сезонные структуры, не наследует
   слепоту одинарных блоков (все пары определены, ни одна не слита) и
   даёт структуру, устойчивую к дневным рефитам там, где это проверяемо.
   Это первый результат в пользу тезиса issue: объединение не разрушает,
   а обогащает сравнение фраз.
2. Но (а) месячный блок рефит не поддаётся (итерация 1) — устойчивость
   combined в целом не подтверждена; (б) месячный блок high_freq
   критерий-зависим (при aicc сезонность отвергнута, итерация 1) — его
   годовой профиль может быть артефактом выбора aic; (в) блоки сняты с
   **разных календарных периодов** (месячные: 2024-08–2026-07, дневные:
   2026-06–08) — combined-вектор смешивает периоды и содержателен только
   при предположении стационарности сезонных форм между ними; (г) пункт
   3–4 MVP (осмысленность кластеров, сравнение с эмбеддингами) на трёх
   фразах одного окна неисполним.
3. **Стоп-условие MVP issue #23 не срабатывало и не срабатывало бы**:
   пункт 2 (устойчивость) по sp=7-части структуры выполнен, по sp=12 —
   непроверяем. Итог по гипотезе остаётся «не опровергнута, не
   подтверждена» — движение к продукту (артефакт-векторы, кластеризация,
   скоринг) блокируется не кодом, а объёмом данных: нужно ≥10 фраз
   (блокировка cli#29 / #34) и длинный месячный ряд (#6) для рефита
   sp=12-блока.

## Чего эта итерация не проверяла

- Кластеризацию и сравнение с эмбеддингами (пункты 3–4 issue) — три
  фразы, см. выше.
- Веса блоков: конкатенация с z-скорением — единственная опробованная
  схема; взвешивание (например, больше веса недельному блоку как более
  устойчивому) не варьировалось.
- Расхождение календарных периодов блоков — не измерялось (нет
  перекрывающихся дневных и месячных окон по одной фразе в фикстурах).
- Причины выбора спецификаций на стыке блоков (у «подарков» sp12
  mul/add/mul при mul/None/mul у «курсов») — наследуются из итераций 1–2,
  здесь не переоткрывались.
