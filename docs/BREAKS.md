# Структурные сдвиги: разрыв в спросе против разрыва в измерении (issue #7)

Часть [Фазы 0](https://github.com/axisrow/wordstat-trends/issues/1). Ядро:
[`src/wordstat_trends/breaks.py`](../src/wordstat_trends/breaks.py), тесты:
[`tests/test_breaks.py`](../tests/test_breaks.py).

Зачем: сезонная модель, принявшая разрыв измерения за спрос, будет ждать
всплеск апреля 2020 каждый апрель и порекомендует закупку не в тот месяц
(прямая денежная ошибка для Фазы 6).

## Границы

- Зоны сбора (#5) и склейки окон (#6) модуль **не выполняет**. Их результат
  входит как вход: `measurement_seams` — периоды, в которых ряд склеен из
  разных окон или сменил методику сбора. Пока #5/#6 не отдадут швы, параметр
  остаётся пустым, а устойчивые сдвиги честно классифицируются как
  `unresolved`.
- Известные даты эпика (2020-03/04 COVID, 2022-03 уход брендов, 2024–2025
  смена интерфейса Вордстата) **не захардкожены**: детектор не содержит ни
  одной даты. Даты передаются как гипотезы (`demand_events`,
  `measurement_seams`) и сопоставляются с найденным через
  `known_dates_coverage` — в том числе с вердиктом «гипотеза не
  подтвердилась», который является результатом, а не ошибкой.

## Метод

### 1. Десезонализация на лог-шкале (`deseasonalize_log`)

Сезонность Вордстата мультипликативна и охватывает 2–3 порядка (декабрь
«новогодних подарков» — 1.2 млн против 22 тыс. в мае, docs/DATA.md). Без
логарифма и удаления профиля детектор видит не сдвиг уровня, а декабрь.

Профиль периода (месяц для freq="M", день недели для freq="D") оценивается
**не** медианой сырого лог-значения своего периода. Это воспроизведено и
отброшено: при наличии сдвига уровня такая медиана смешивает до- и
пост-сдвиговые годы, профиль «расщепляется» пополам и создаёт ложные разрывы
каждые 6 месяцев (на синтетике: 8 ложных точек на ряде с одним сдвигом ×5).
Вместо этого:

1. из лог-ряда вычитается центрированная скользящая медиана (окно 12
   месяцев — ровно один проход по всем месяцам года) — локальный уровень,
   робастный и к сдвигу, и к одиночному выбросу;
2. профиль периода — медиана этих отклонений по своему периоду; у периода с
   менее чем двумя наблюдениями профиль не оценивается (фактор 0), иначе
   единственное наблюдение оценило бы «сезонность» самого себя;
3. остаток = лог-ряд минус профиль. Уровень (включая подлинные сдвиги)
   остаётся в остатке, сезонный декабрь — нет.

Краевое окно: неполное скользящее окно даёт сезонно смещённую медиану и
ложные разрывы на краях ряда (воспроизведено на реальной фикстуре: ложный
разрыв в декабре 2025). Поэтому `min_periods` равен полному окну, а краям
уровень переносится от ближайшего полного окна. **Ограничение:** разрыв в
пределах ~6 месяцев от края ряда ненадёжен — для 24-месячного ряда это
существенно, и это одна из причин, почему вердикты по текущим фикстурам
предварительные.

Ещё два краевых случая зафиксированы явно. (1) Шок с первого периода ряда:
до-разрывного периода не существует, `at` — первый период нового режима,
помечено `evidence["at_series_start"]`; ряд, целиком состоящий из шока,
заменять нечем — детекция уровней на нём возвращает пустой список. (2) Если
какой-то месяц отсутствует в индексе целиком (например, после `truncate_series`),
профиль для него считается нулевым, а не падает с KeyError.

### 2. Два детектора под два явления

| Явление | Длительность | Детектор |
|---|---|---|
| Переходный шок спроса (COVID-2020: spike и возврат) | 1–2 месяца | робастная z-оценка **локального** отклонения (остаток минус его центрированная скользящая медиана окна 13) с двухусловным правилом \|z\| > 3.5 И амплитуда ≥ 0.3 лог-единиц (`detect_spike_months`); шок ищется **в обе стороны** — отрицательный провал равноправен положительному |
| Разрыв уровня (уход брендов, смена методики) | устойчивый | `ruptures` Pelt (или Binseg), модель l2, на остатке |

Локальная база у шок-детектора обязательна: против медианы всего ряда
устойчивый сдвиг уровня помечает «выбросом» весь пост-сдвиговый сегмент
(воспроизведено: серия длиной 24 месяца на ряде с одним сдвигом ×5), а
ступеньки скользящего уровня дают ложные шоки на чистом ряду.

Pelt с `min_size=3` переходный шок из 1–2 месяцев не видит **по построению**
(сегмент короче min_size), поэтому шоки ищутся отдельно и до разрывов.
Серия подряд идущих месяцев-выбросов — один шок, не несколько. Перед
детекцией уровней месяцы-выбросы заменяются средним соседей: иначе шок
расщепляет сегмент и маскирует сдвиг уровня.

### Предрегистрированные параметры

Зафиксированы до прогона на реальных фикстурах. Ревизия 2026-09 (в рамках
ревью этого PR): база шок-детектора заменена с глобальной медианы на
локальную (окно 13) после воспроизведённого фейла (пост-сдвиговый сегмент
помечался выбросом целиком), порог перекалиброван 3.0 → 3.5; прежняя
фиксация отменена этой ревизией:

| Параметр | Значение | Обоснование |
|---|---|---|
| `PELT_PENALTY` | 1.0 | единицы квадрата остатка; калибровка — синтетика (шум ~3 % без сдвига → 0 точек, сдвиг ×5 → 1 точка) |
| `MIN_SEGMENT_SIZE` | 3 | на месячном ряде сдвиг короче 3 месяцев неотличим от переходного шока |
| `SPIKE_Z_THRESHOLD` | 3.5 | \|z\| — двусторонний поиск (отрицательный провал равноправен); за пределами шума месячной гранулярности |
| `SPIKE_MIN_ABS_LOG` | 0.3 | двухусловное правило (z И амплитуда ≥ 0.3, т.е. ±35 %): при эмпирически тесном MAD тяжеловатый шум достигает z ≈ 3.5–4 на амплитудах ~8 %, содержательный шок — десятки процентов |
| `PROFILE_WINDOW` | 12 | один проход по всем месяцам года |
| `REVERT_HORIZON` | 2 | COVID-подобный шок возвращается за 1–2 месяца |
| `REVERT_TOLERANCE` | 0.5 | возвратом считается снижение отклонения до половины сдвига |
| `KNOWN_DATE_TOLERANCE` | 1 | min_size и месячная гранулярность сдвигают границу на соседний период |

## Классификация (по убыванию приоритета)

1. **`demand_transient`** — возврат к до-разрывному уровню за
   `REVERT_HORIZON` месяцев (либо шок по z-детектору). Реальное событие,
   модель видит его сам.
2. **`measurement`** — устойчивый сдвиг, первый месяц нового режима лежит на
   шве измерения (`measurement_seams` из #5/#6).
3. **`demand_persistent`** — устойчивый сдвиг на известном содержательном
   событии (`demand_events`).
4. **`unresolved`** — устойчивый сдвиг без внешних оснований. Из самого ряда
   спрос и измерение в этом случае **неразличимы** — честный вердикт, а не
   догадка.

## Решения по обработке (требование эпика, не опция)

Каждый разрыв получает решение (`decide_handling`), «решения нет» не
существует:

| Тип | Решение | Обоснование |
|---|---|---|
| `demand_transient` | `keep` | уровень вернётся сам; дамми занизил бы аналог в следующем году |
| `demand_persistent` | `dummy` | индикатор «после даты» (`add_dummy`), ряд не теряется |
| `measurement` | `truncate` | до-разрывная часть собрана другой методикой (`truncate_series`) |
| `unresolved` | `segment` | сегментная модель по разрыву; финальное слово — за этим отчётом и человеком |

## Что измерено на реальных данных

Три месячные фикстуры MVP #23 («новогодние подарки», «курсы английского
языка», «купить телефон»; 2024-08 — 2026-07, 24 месяца,
`scripts/experiment_vector_d.load_dynamics_csv`):

| Фраза | Найдено разрывов |
|---|---|
| новогодние подарки | 0 |
| курсы английского языка | 0 |
| купить телефон | 0 |

Интерпретация: в текущем 24-месячном окне детектор не находит ни сдвигов
уровня, ни шоков сверх сезонного профиля. Известные даты эпика (2020, 2022)
в данных **физически отсутствуют** — окно начинается в августе 2024, поэтому
валидация детектора на них синтетическая (ниже). Вердикт по 2024–2025
(смена интерфейса Вордстата): разрыв мог бы лежать только у края ряда, где
детекция ненадёжна (см. краевое окно), — подтверждать его нечем, гипотеза
остаётся открытой до расширения окна сбора вглубь истории.

## Синтетическая валидация (известных дат в данных нет)

Синтетика — основной контур проверки (`tests/test_breaks.py`): ряд 60
месяцев, мультипликативная сезонность ×(0.3…6), шум 3 %, seed=0.

| Сценарий | Ожидание | Результат |
|---|---|---|
| чистый сезонный ряд | 0 разрывов — декабрь не разрыв | 0 ✓ |
| spike ×4 на 2 месяца (COVID-форма) | `demand_transient`, `keep` | 1 точка, верно ✓ |
| spike ×0.2 (провал, отрицательный шок) | `demand_transient`, `delta_log < 0` | верно ✓ |
| шок с первого месяца ряда | `at` = первый период, `at_series_start` | верно ✓ |
| ряд целиком из шока | без падения, 0 разрывов уровня | верно ✓ |
| сдвиг ×5 на шве склейки (#6 отдаст шов) | `measurement`, `truncate` | верно ✓ |
| сдвиг ×5 без контекста | `unresolved`, `segment` | верно ✓ |
| тот же сдвиг на известной дате события | `demand_persistent`, `dummy` | верно ✓ |
| известная дата без разрыва | «не подтверждена» в coverage | верно ✓ |
| ряд из 5 месяцев | 0 разрывов (меньше 2·min_size) | 0 ✓ |
| профиль месяца | сезонная амплитуда убрана | остаток — константа ✓ |
| месяц отсутствует в индексе (после truncate) | нулевой профиль, не KeyError | верно ✓ |

## Интеграция

- Вход рядов — `pd.Series` c `PeriodIndex` (freq="M" или "D"); загрузчики
  остаются в зоне сбора (#5/#6) и скриптов, модуль их не дублирует.
- Швы склейки окон и смен методики подключаются параметром
  `measurement_seams`, как только #5/#6 начнут их отдавать; до тех пор
  устойчивые сдвиги не получают тип `measurement` без оснований.
- Отчёт структуры данных — `build_breaks_report` (точки, типы, решения,
  покрытие известных дат); витрина (#14) рендерит его, когда появится.
